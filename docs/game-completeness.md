# 게임 완성도 지표와 폐쇄 루프

## 결정론적 게임 루프

```text
일정 선택 → 상태 전이(스탯/은화/기록) → 4·8주차 사건 선택 → 12주 엔딩 판정
       ↑                                                        ↓
       └────────────── 다시 시작 / 동일 입력 재현 ──────────────┘
```

모든 콘텐츠는 [`story/story.json`](../story/story.json)에 있고, 입력 순서가 같으면 동일한 상태가 나온다. 이벤트는 4·8주차에 고정되고, 엔딩은 12주에 고정된다.

## 현재 증적 지표

| 지표 | 기준 | 현재 |
| --- | --- | ---: |
| 활동 조합 공간 | 활동 3개 × 12주 | 36 |
| 성장 축 | 지혜·공감·용기 | 3 |
| 성격 대화 | 독립 성격 3개 | 3 |
| 분기 사건 | 4·8주차 × 선택 2개 | 2 × 2 |
| 시각 회귀 | 홈·일러스트·엔딩 Golden | 3 |
| 자동 게이트 | SSOT 검사·Flutter test·Wasm | 3 |

검증 스크립트는 [`tool/verify_game.dart`](../tool/verify_game.dart)이며, 실패 시 0이 아닌 종료 코드로 CI를 중단한다. 현재 콘텐츠·렌더링·자동화 기준 점수는 100%로 측정되지만, 장기 완성도에서 저장 슬롯과 외부 리플레이 내보내기는 다음 설계 단계로 명시한다.
