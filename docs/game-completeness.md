# 게임 완성도 지표와 폐쇄 루프

## 결정론적 게임 루프

```text
일정 선택 → 상태 전이(스탯/은화/피로/기록) → 3·6·9·10주차 사건 선택 → 12주 엔딩 판정
       ↑                                                        ↓
       └────────────── 다시 시작 / 동일 입력 재현 ──────────────┘
```

모든 콘텐츠는 [`story/story.json`](../story/story.json)에 있고, 입력 순서가 같으면 동일한 상태가 나온다. 이벤트는 3·6·9·10주차에 고정되고, 엔딩은 12주에 고정된다.

## 현재 증적 지표

| 지표 | 기준 | 현재 |
| --- | --- | ---: |
| 활동 조합 공간 | 활동 5개 × 12주 | 60 |
| 성장 축 | 지혜·공감·용기 | 3 |
| 리스크 축 | 피로 0–12, 휴식/과로/성장 페널티 | 1 |
| 성격 대화 | 독립 성격 3개 + 성장축 재능 보너스 | 3 + 3 |
| 동료 관계 | 루미·보라·타로 유대 0–100 + 임계 에필로그 | 3 + 3 |
| 장기 목표 | 봄·여름·가을·겨울 목표/보상/성공·실패 피드백 | 4 |
| 엔딩 콘텐츠 | 스탯별 SSOT 엔딩 6개(기본/숙련) | 6 |
| 분기 사건 | 4개 사건 × 선택 2개 | 4 × 2 |
| 조건부 선택 | 용기 성장 조건이 있는 잠금 선택지 | 3 |
| 시각 회귀 | 홈·계절 목표·사건·일러스트·엔딩·replay 보관소·재시작 Golden | 7 |
| canonical 통합 경로 | 실제 `story/story.json` 12주 완주·사건 4개·목표 4개·에필로그 | 1 |
| 종료 불변식 | 12주 완료 뒤 추가 활동 입력 차단 + 새 세션 재시작 | 1 |
| Canvas 입력 계약 | 활동·일러스트·성격 탭·일러스트 복귀·사건·보관소 좌표 회귀 | 1 |
| personality campaign 경로 | 지혜·공감·용기 각 성격의 숙련 엔딩 재현 | 3 |
| 글리프 안정성 | 번들 Noto Sans KR + Canvas 벡터 활동 아이콘 | 1 |
| 자동 게이트 | SSOT 검사·해시 매니페스트·정적 분석·Flutter test·Wasm | 4 |
| 저장/replay | 행동·사건 후 자동 `lumen-save-v6` snapshot + WASM `localStorage` 새로고침 복원 + trace round trip | 1 |

검증 스크립트는 [`tool/verify_game.dart`](../tool/verify_game.dart)이며, 콘텐츠·분기·결정론·시각 회귀·자산·추적성·배포·입력 계약 8개 차원을 실제 파일과 SSOT에서 계산하고 95% 미만이면 실패한다. 저장 코드는 [`lib/save_state.dart`](../lib/save_state.dart)의 `lumen-save-v6` 형식으로 복사/복원되고 v3/v4/v5 입력도 호환하며, `history` trace·동료 유대·계절 목표·마지막 행동 결과·사건 대사가 동일하게 보존된다. 피로 8 이상에서는 활동 성장량이 1 감소하고 휴식은 피로를 낮추며, 은화는 코어에서 0–999 범위로 제한된다. 성격 선택은 대응 성장축에 +1 재능을 주고 선택 카드에도 표시하며, 사건 선택은 동료 유대를 최대 100까지 올려 위험-보상·관계·피드백 루프를 만든다. 조건부 사건 선택은 UI와 `GameSession` 코어 양쪽에서 잠금 검증된다. 계절 목표는 사건 선택 후 판정되어 성공 보상 또는 실패 문구를 남기며, 숙련 엔딩은 SSOT에 선언된 계절 목표를 모두 달성해야 선택되고 미달 시 기본 엔딩으로 결정론적으로 내려간다. 임계 유대에 도달하면 엔딩에 동료 에필로그가 결정론적으로 붙고, 12주 이후 코어는 추가 활동 입력을 거부한다. Canvas Golden 회귀에는 성격 탭 선택과 일러스트 화면의 홈 복귀 입력도 포함된다.
